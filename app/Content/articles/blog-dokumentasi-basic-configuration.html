Saya membuat catatan konfigurasi supaya tidak perlu mengingat semua alamat dan port di home lab. Isinya hal-hal yang sering saya butuhkan: pembagian VLAN, gateway, DNS, alamat server, koneksi switch, serta perintah untuk mengecek layanan. Catatan ini saya kumpulkan di bagian Basic Configuration.

Mulai dari alamat dan port perangkat

Untuk jaringan, saya mencatat ether4 MikroTik yang terhubung ke GE1 Cisco sebagai trunk VLAN 10, 20, dan 30. Setelah itu saya tulis pembagian access port: FE1/FE2 untuk management, GE2 untuk server, dan FE3 untuk client. Daftar ini membantu saya mencari jalur perangkat ketika terjadi masalah koneksi.

Saya juga menyimpan subnet, gateway, dan pool DHCP tiap VLAN. Misalnya, server berada di 192.168.20.0/24 dengan gateway 192.168.20.1, sedangkan DNS-nya 192.168.20.199. Dengan catatan tersebut saya bisa membandingkan pengaturan client dengan segmen yang seharusnya dipakai.

Mencatat perintah yang sering dipakai

Di Debian saya mulai dari alamat interface, route, dan resolver. Kalau jaringan sudah terhubung, saya lanjut mengecek container dan log aplikasi. Perintah yang saya pakai antara lain:

ip -brief address show ens18
ip route
cat /etc/resolv.conf
sudo dhcpcd -U ens18
ping -c 3 192.168.20.1
getent ahostsv4 azrilachdi.web.id
cd /mnt/data/docker-compose/portfolio/repository
sudo docker compose --env-file ../runtime.env ps
sudo docker compose --env-file ../runtime.env logs --tail=50 app

Mengikuti jalur koneksi saat mencari masalah

Kalau client tidak mendapat IP, saya cek port switch, VLAN, dan DHCP. Kalau IP sudah ada tetapi domain gagal dibuka, saya cek gateway serta DNS. Untuk website, saya coba origin di Debian terlebih dahulu, kemudian proxy, tunnel WireGuard, dan akses domain publik.

Saya menulis hasilnya bersama bagian yang diubah. Sebelum mengubah konfigurasi, saya simpan backup agar bisa kembali ke pengaturan sebelumnya jika diperlukan. Untuk SSH, saya juga menjaga sesi yang masih terhubung sampai koneksi baru berhasil dicoba.

Catatan lengkapnya ada di Basic Configuration Jaringan dan Server. Susunan perangkatnya bisa dilihat di Home Lab.
