Home lab saya menghubungkan pembelajaran jaringan dengan pengoperasian aplikasi yang benar-benar digunakan. MikroTik mengatur gateway dan DHCP, Cisco SF200-24 membagi koneksi ke segmen management, server, dan client, sementara Proxmox menyediakan lingkungan server sesuai topologi pribadi saya. Website portofolio ini berjalan di Debian dengan Docker.

Dari jalur fisik ke jaringan logis

Sketsa saya menempatkan ONT/upstream menuju ether1 MikroTik. Uplink ke Cisco memakai ether4 MikroTik dan GE1 switch. Backup mengonfirmasi ketiga interface VLAN berada pada ether4. Tangkapan layar Cisco menunjukkan GE1 sebagai trunk VLAN 10/20/30, sehingga jalur fisik dan konfigurasi logis dapat dicocokkan.

Peran masing-masing server

Proxmox merespons pada 192.168.20.200:8006. Technitium DNS berada di 192.168.20.199 dan menjadi resolver Debian. Debian Web Server di 192.168.20.195 menjalankan container portofolio, database, dan Nginx Proxy Manager. Detail bridge, VM ID, alokasi CPU/RAM, dan penyimpanan Proxmox belum diperiksa, sehingga tidak saya cantumkan sebagai spesifikasi.

Mengapa saya membandingkan gambar dengan keadaan server

Gambar awal mencatat IP statis melalui Winbox. Ketika diperiksa dari Debian, interface ens18 masih menggunakan DHCP dengan lease 30 menit. Perbedaan seperti ini penting: dokumen yang tampak rapi bisa membuat troubleshooting salah arah jika keadaan nyata berbeda. Saya mencatat nilai yang diamati dan membedakannya dari rencana maupun informasi yang belum diverifikasi.

ip -brief address show ens18
ip route
cat /etc/resolv.conf
sudo dhcpcd -U ens18
ping -c 3 192.168.20.1
getent ahostsv4 azrilachdi.web.id

Aplikasi dan akses dari luar

Domain portofolio melewati Nginx Azure, tunnel WireGuard, dan Nginx Proxy Manager sebelum mencapai container. Dengan demikian, kegagalan website bisa berasal dari DNS, tunnel, proxy, atau aplikasi. Memeriksa origin lebih dulu membantu mempersempit penyebab. Tailscale saya catat sebagai jalur VPN pribadi terpisah karena penempatan node belum diperiksa.

Pelajaran utama home lab ini adalah menjaga hubungan antara perangkat, konfigurasi, dan bukti pengujian. Dokumentasi home lab memuat inventaris dan topologi, sedangkan Basic Configuration menjadi panduan pemeriksaan harian.
