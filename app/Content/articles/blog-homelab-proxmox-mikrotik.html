Home lab ini tempat saya belajar jaringan dan server sekaligus menjalankan aplikasi sendiri. Saya memakai MikroTik sebagai router, Cisco SF200-24 sebagai managed switch, dan Proxmox untuk lingkungan server. Salah satu aplikasi yang berjalan di lab ini adalah website portofolio yang sedang Anda buka.

Membagi jaringan dengan MikroTik dan Cisco

Koneksi dari ONT masuk ke ether1 MikroTik. Dari ether4, koneksi diteruskan ke GE1 Cisco dengan trunk VLAN 10, 20, dan 30. Saya membaginya menjadi jaringan management, server, dan client supaya perangkat lebih mudah dikelompokkan.

PC management berada di VLAN 10, layanan server di VLAN 20, sedangkan access point TP-Link dan client berada di VLAN 30. Pada switch, FE1 dan FE2 dipakai untuk management, GE2 untuk server, dan FE3 untuk client. Setiap VLAN memiliki subnet dan gateway sendiri.

Layanan yang saya jalankan

Saya mengakses Proxmox di 192.168.20.200:8006. Technitium DNS berada di 192.168.20.199, sementara Debian Web Server memakai 192.168.20.195. Debian menjalankan container aplikasi, database, dan Nginx Proxy Manager.

Di Debian, interface jaringan bernama ens18 dan menggunakan DHCP. Gateway-nya 192.168.20.1 dengan DNS 192.168.20.199. Perintah berikut membantu saya melihat alamat, route, dan resolver yang sedang dipakai server.

ip -brief address show ens18
ip route
cat /etc/resolv.conf
sudo dhcpcd -U ens18
ping -c 3 192.168.20.1
getent ahostsv4 azrilachdi.web.id

Menghubungkan layanan lokal ke internet

Untuk website publik, saya memakai Azure VPS yang terhubung ke MikroTik melalui WireGuard. Request diteruskan ke Nginx Proxy Manager di Debian, lalu ke container portofolio. Saya juga menggunakan Tailscale untuk akses VPN pribadi.

Dari lab ini saya belajar bahwa menjalankan aplikasi juga melibatkan jaringan, DNS, dan pengelolaan server. Kalau website bermasalah, saya perlu menelusuri tiap bagian itu, mulai dari layanan lokal sampai akses domain. Susunan perangkat dan alamatnya ada di halaman Home Lab.
