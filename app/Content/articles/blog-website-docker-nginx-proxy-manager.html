Website portofolio ini saya jalankan di Debian menggunakan Docker. Aplikasinya memakai CodeIgniter 4, PHP 8.3, dan Apache, dengan MariaDB 11.4 sebagai database. Nginx Proxy Manager menangani penerusan request dari domain ke container aplikasi.

Menyiapkan koneksi antarcontainer

Container aplikasi memiliki alias portfolio-web pada network web-proxy. Alias ini menjadi tujuan proxy host di Nginx Proxy Manager, dengan port tujuan 80. MariaDB berada di network backend internal dan tidak membuka port database ke host.

Saya juga memetakan aplikasi ke 127.0.0.1:18081 agar bisa diperiksa langsung dari Debian. Saat mengecek origin ini, saya menyertakan header X-Forwarded-Proto: https karena aplikasi menggunakan cookie Secure pada lingkungan produksi.

curl --fail --header 'X-Forwarded-Proto: https' http://127.0.0.1:18081/ -o /dev/null

Memisahkan aplikasi dan data

Database, file unggahan, dan direktori writable disimpan di /mnt/data/storage/portfolio. Source dan dependency masuk ke image Docker, sementara data tetap berada pada volume. Pemisahan ini membuat image aplikasi bisa diperbarui tanpa ikut mengganti database dan file yang sudah diunggah.

Meneruskan request HTTPS

Pengunjung masuk melalui HTTPS ke Azure VPS. Setelah melewati WireGuard, request diterima Nginx Proxy Manager di Debian dan diteruskan ke portfolio-web:80. Header Host dan X-Forwarded-Proto dipertahankan supaya aplikasi membaca domain serta skema request dengan benar.

Memperbarui website dari repository

Push ke branch main menjalankan GitHub Actions untuk build dan pengujian. Timer di Debian kemudian memasang commit yang sudah lulus CI. Sebelum migrasi, script deployment menyimpan backup database dan memeriksa kesehatan aplikasi setelah container baru berjalan.

sudo systemctl status portfolio-deploy.timer --no-pager
sudo journalctl -u portfolio-deploy.service -n 50 --no-pager

Kalau domain gagal tetapi origin masih merespons, saya mengecek proxy, tunnel, dan DNS. Kalau origin ikut gagal, saya mulai dari log aplikasi dan koneksi database. Potongan Compose serta perintah operasionalnya saya simpan di dokumentasi Docker dan Nginx Proxy Manager.
