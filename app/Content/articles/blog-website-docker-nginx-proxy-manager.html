Portofolio ini menjadi salah satu aplikasi yang saya jalankan di Debian Web Server. Stack-nya terdiri dari CodeIgniter 4, PHP 8.3, Apache, dan MariaDB 11.4. Docker menyatukan kebutuhan runtime aplikasi, sedangkan Nginx Proxy Manager menghubungkan domain ke container yang sesuai.

Origin yang dapat diperiksa langsung

Port aplikasi dipetakan ke 127.0.0.1:18081. Container juga memiliki alias portfolio-web pada network web-proxy, yang menjadi tujuan proxy host. MariaDB berada pada network backend internal dan tidak membuka port ke host. Pemisahan ini membantu pemeriksaan: origin dapat diuji dari Debian sebelum mengikuti jalur akses luar.

curl --fail --header 'X-Forwarded-Proto: https' http://127.0.0.1:18081/ -o /dev/null

Build aplikasi dan data persisten

Database, unggahan, dan writable disimpan pada direktori /mnt/data/storage/portfolio. Image baru membawa source serta dependency aplikasi, sementara data tetap berada di volume. Karena konten website disimpan dalam database, perubahan tampilan saja tidak otomatis mengganti artikel atau proyek contoh. Pembaruan konten harus menjadi langkah yang terencana dan memiliki backup.

Header kecil yang memengaruhi perilaku aplikasi

TLS diakhiri pada Azure, sehingga aplikasi menerima trafik HTTP dari proxy. Host dan X-Forwarded-Proto mempertahankan konteks request asli. Health check proyek menyertakan X-Forwarded-Proto: https agar pemeriksaan origin sesuai dengan cookie dan pengaturan produksi. Memeriksa jalur lokal dengan konteks berbeda dapat menghasilkan kesimpulan yang keliru.

Deployment berdasarkan commit yang sudah lolos CI

GitHub Actions membangun image dan menguji database kosong serta halaman publik. Timer Debian kemudian memasang SHA main yang memiliki hasil CI sukses. Script deployment mengambil snapshot database sebelum migrasi, memeriksa health check, dan mencoba rollback image jika gagal. Hal ini membuat perubahan source dan pembaruan konten dapat ditelusuri ke commit yang sama.

sudo systemctl status portfolio-deploy.timer --no-pager
sudo journalctl -u portfolio-deploy.service -n 50 --no-pager

Dokumentasi Docker dan reverse proxy memuat cuplikan Compose serta perintah operasi yang sesuai dengan repository ini.
