GE1 Cisco harus tetap membawa tag VLAN 10/20/30 menuju ether4 MikroTik. Client pada access port menerima trafik untagged dalam VLAN sesuai PVID. Debian saat pemeriksaan memakai DHCP; jangan mengubahnya menjadi statis hanya karena catatan topologi awal menyebut reservasi melalui Winbox.

Routing dan firewall

/ip route print
/ip firewall filter print stats
/ip firewall nat print stats
/ip service print

Router adalah gateway antarsegmen. Backup menyimpan aturan dengan sasaran pembatasan VLAN 30 menuju Cisco di 192.168.10.2, Proxmox di 192.168.20.200:8006, dan Winbox gateway di 192.168.10.1:8291. Backup juga mencatat pembatasan dari peer VPS ke LAN lain. Ini menunjukkan kebijakan yang disusun, tetapi tidak membuktikan seluruh isolasi sedang efektif. Counter, urutan rule, serta jalur akses dari tiap VLAN harus diuji sebelum menyebut segmentasi aman.

Health check origin yang berhasil membantu membedakan error aplikasi dari error proxy. MariaDB memakai network internal; port aplikasi host hanya tersedia pada loopback. Konfigurasi proxy yang sudah ada meneruskan domain ke portfolio-web:80 pada web-proxy.

VPN dan akses dari luar

Periksa interface wg-azure, IP 10.10.0.2, peer VPS 10.10.0.1, handshake, dan jalur balik sebelum memeriksa HTTP. Tailscale dicatat sebagai akses pribadi sesuai informasi saya, dengan detail node/rute yang belum diperiksa. Jangan memakai hasil tes website sebagai bukti bahwa semua layanan administrasi dapat diakses dari VPN.

Mencatat perubahan

Simpan konfigurasi sebelum perubahan, tuliskan perangkat dan port yang diubah, catat hasil uji, dan siapkan cara kembali ke konfigurasi sebelumnya. Backup MikroTik asli tetap disimpan di luar website. Artikel ini hanya memuat nilai konfigurasi yang relevan untuk penjelasan, tanpa kredensial jaringan.
