Di home lab saya, MikroTik menjadi gateway untuk VLAN 10, 20, dan 30. Ketiganya memakai ether4 sebagai uplink ke GE1 Cisco SF200-24. Saya memakai VLAN 10 untuk management, VLAN 20 untuk server, dan VLAN 30 untuk client serta access point TP-Link.

Pengaturan port Cisco

GE1 memakai trunk dengan VLAN 10/20/30 tagged dan VLAN 1 untagged, PVID 1. FE1 dan FE2 memakai access VLAN 10, GE2 access VLAN 20, dan FE3 access VLAN 30. Pada FE4–FE24, membership yang tercatat adalah VLAN 1 untagged dengan PVID 1.

Interface VLAN, gateway, dan pool

Berikut contoh penulisan CLI untuk interface dan alamat yang saya pakai. Pada router yang sudah memiliki entri ini, saya mengecek konfigurasi terlebih dahulu agar tidak menambahkan entri ganda.

/interface vlan
add interface=ether4 name=vlan10-management vlan-id=10
add interface=ether4 name=vlan20-server vlan-id=20
add interface=ether4 name=vlan30-client vlan-id=30
/ip address
add address=192.168.10.1/24 interface=vlan10-management
add address=192.168.20.1/24 interface=vlan20-server
add address=192.168.30.1/24 interface=vlan30-client
/ip pool
add name=dhcp_pool0 ranges=192.168.10.100-192.168.10.200
add name=dhcp_pool1 ranges=192.168.20.100-192.168.20.200
add name=dhcp_pool2 ranges=192.168.30.100-192.168.30.200

DHCP dan DNS client

dhcp1, dhcp2, dan dhcp3 melayani VLAN masing-masing dengan lease 30 menit. Ketiga scope membagikan alamat Technitium 192.168.20.199 sebagai DNS. Debian menerima gateway 192.168.20.1 dan resolver yang sama melalui DHCP.

/ip dhcp-server
add name=dhcp1 interface=vlan10-management address-pool=dhcp_pool0 lease-time=30m disabled=no
add name=dhcp2 interface=vlan20-server address-pool=dhcp_pool1 lease-time=30m disabled=no
add name=dhcp3 interface=vlan30-client address-pool=dhcp_pool2 lease-time=30m disabled=no
/ip dhcp-server network
add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=192.168.20.199
add address=192.168.20.0/24 gateway=192.168.20.1 dns-server=192.168.20.199
add address=192.168.30.0/24 gateway=192.168.30.1 dns-server=192.168.20.199

Mengecek koneksi client

Saya mulai dari membership VLAN dan PVID pada switch, lalu membandingkannya dengan interface di MikroTik. Sesudah itu saya lihat alamat IP, gateway, DNS, dan lease client. Mode trunk perlu dicek bersama daftar VLAN yang dilewatkan agar pengaturan uplink di kedua perangkat cocok.

/interface vlan print detail
/ip address print
/ip pool print
/ip dhcp-server print detail
/ip dhcp-server network print
/ip dhcp-server lease print

Kalau client sudah mendapat alamat yang sesuai, saya lanjut mencoba gateway dan layanan yang dibutuhkan. Untuk akses antar-VLAN, saya juga melihat rule firewall dan counter paket pada MikroTik.
