Tiga segmen dengan fungsi berbeda

MikroTik menjadi gateway setiap VLAN. Ketiga interface VLAN berada pada ether4 yang terhubung ke GE1 Cisco. VLAN 10 dipakai untuk management, VLAN 20 untuk server, dan VLAN 30 untuk client. Access point TP-Link berada pada cabang client sesuai sketsa fisik saya.

Pemetaan Cisco SF200-24

GE1 menggunakan mode trunk dengan VLAN 10, 20, dan 30 tagged. VLAN 1 tetap untagged dan menjadi PVID 1. GE2 adalah access port dengan PVID 20. FE1 dan FE2 memakai PVID 10, sedangkan FE3 memakai PVID 30. FE4–FE24 terlihat dalam mode trunk/PVID 1; tangkapan layar tidak menunjukkan bahwa port tersebut membawa VLAN 10/20/30.

Interface VLAN dan alamat MikroTik

/interface vlan
add interface=ether4 name=vlan10-management vlan-id=10
add interface=ether4 name=vlan20-server vlan-id=20
add interface=ether4 name=vlan30-client vlan-id=30
/ip address
add address=192.168.10.1/24 interface=vlan10-management
add address=192.168.20.1/24 interface=vlan20-server
add address=192.168.30.1/24 interface=vlan30-client
/ip pool
add name=dhcp_pool0 ranges=192.168.10.100-192.168.10.200
add name=dhcp_pool1 ranges=192.168.20.100-192.168.20.200
add name=dhcp_pool2 ranges=192.168.30.100-192.168.30.200

DHCP per VLAN

dhcp1, dhcp2, dan dhcp3 masing-masing mengacu pada interface VLAN 10, 20, dan 30. Lease time pada backup adalah 1800 detik atau 30 menit. DNS yang dibagikan adalah 192.168.20.199. Lease aktif Debian mengonfirmasi gateway 192.168.20.1 dan DNS yang sama.

/ip dhcp-server
add name=dhcp1 interface=vlan10-management address-pool=dhcp_pool0 lease-time=30m disabled=no
add name=dhcp2 interface=vlan20-server address-pool=dhcp_pool1 lease-time=30m disabled=no
add name=dhcp3 interface=vlan30-client address-pool=dhcp_pool2 lease-time=30m disabled=no
/ip dhcp-server network
add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=192.168.20.199
add address=192.168.20.0/24 gateway=192.168.20.1 dns-server=192.168.20.199
add address=192.168.30.0/24 gateway=192.168.30.1 dns-server=192.168.20.199

Pemeriksaan sebelum mengubah konfigurasi

/interface vlan print detail
/ip address print
/ip pool print
/ip dhcp-server print detail
/ip dhcp-server network print
/ip dhcp-server lease print

Di Cisco, cocokkan menu Interface Settings, Port to VLAN, dan VLAN Membership. Mode trunk saja belum membuktikan keanggotaan VLAN. Periksa tag dan PVID pada kedua ujung uplink, lalu periksa IP, gateway, DNS, dan konektivitas client. Backup juga memuat pool di subnet 192.168.26.0 dan 192.168.40.0; keduanya tidak saya gambar sebagai VLAN aktif karena tidak ada interface VLAN terkait dalam bagian konfigurasi yang diperiksa.
