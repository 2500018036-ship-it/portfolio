Saya menghubungkan Azure VPS ke home lab melalui WireGuard pada MikroTik. Jalur ini dipakai untuk meneruskan akses website dari internet ke Debian Web Server. Selain itu, saya memakai Tailscale untuk akses VPN pribadi.

Parameter WireGuard

Interface pada MikroTik bernama wg-azure. Alamat tunnel router adalah 10.10.0.2/24 dengan peer VPS 10.10.0.1. Endpoint publiknya 20.194.8.143:51820 dan persistent keepalive 25 detik. Domain portofolio mengarah ke IP publik VPS tersebut.

Mengecek status peer

Saya melihat endpoint aktif, waktu handshake terakhir, serta trafik RX/TX untuk mengecek koneksi antarpeer. Perintah berikut dipakai pada MikroTik yang sudah memiliki konfigurasi tunnel.

/interface wireguard print
/ip address print where interface=wg-azure
/interface wireguard peers print proplist=interface,current-endpoint-address,current-endpoint-port,last-handshake,rx,tx

Routing dan firewall ke layanan web

Rule VPS-NEXTCLOUD memakai sumber 10.10.0.1, tujuan 192.168.20.195, dan port TCP 80/443. Pada alamat Debian tersebut, Nginx Proxy Manager meneruskan request ke container aplikasi. Ada juga rule pembatasan dari VPS ke jaringan LAN lain.

Untuk mengecek forwarding, saya melihat route menuju layanan, jalur balik, urutan rule, dan counter paket. Handshake yang berhasil tetap perlu diikuti percobaan akses ke layanan yang dituju.

Akses website dari luar

Saya mulai dari DNS domain, kemudian tunnel, akses HTTP di Debian, dan log reverse proxy. Setelah origin merespons, saya mencoba domain melalui HTTPS. Kunci WireGuard tetap disimpan pada perangkat dan tidak saya sertakan dalam catatan ini.

Tailscale untuk akses pribadi

Saya menggunakan Tailscale sebagai jalur VPN pribadi. Catatan parameter di atas berfokus pada tunnel WireGuard antara Azure dan MikroTik; pemasangan node serta kebijakan akses Tailscale dikelola terpisah dari publikasi website.
